# 跟读练习本 · YouTube Shadowing

在 YouTube 视频旁边逐句听英文、慢速循环、录音跟读并回听的 Chrome 扩展。中文界面，无需 API Key、账号注册或安装依赖。

## 安装到 Chrome

1. 打开 Chrome，在地址栏输入 `chrome://extensions`。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择目录 **`F:\Claude\Work\youtube-shadowing`**，即包含 `manifest.json` 的这一层目录。
5. 打开或刷新一个 YouTube 普通视频页面，「跟读练习本」会嵌入右侧推荐栏顶部；窄窗口下显示在播放器下方，不遮挡页面。

也可在 Edge 的 `edge://extensions` 使用相同方式加载；主要面向 Chrome 开发。修改文件后需在扩展管理页点击刷新，再刷新 YouTube。

## 功能

- 优先加载英文人工字幕，其次英文自动字幕。
- 选择字幕，播放该句，到句尾自动暂停。
- 支持循环重听，循环间隔 1.2 秒；速度为 0.6× / 0.75× / 0.9× / 1.0× / 1.25×。
- 使用麦克风录音，最长 60 秒；录完回听，也可下载 WebM（部分环境为 M4A）。
- 搜索字幕、上下句切换、定位当前视频时间对应的字幕。
- 支持 UTF-8 SRT / VTT 导入，最大 5 MB / 10000 句。
- 字幕接口不可用时，可开启 YouTube 英文 CC，再点击「收集屏幕字幕」，逐步收集正在显示的内容。
- 记住播放速度与循环设置；面板支持收起，Esc 可关闭。

## 使用方式

选一个带英文字幕的视频，选中一句 →「听这一句」→「开始录音」→「停止录音」→ 回听自己的声音 → 再次播放原声比较节奏、重音和连读。首次录音需允许 **YouTube 网站**使用麦克风。

`examples/practice.vtt` 是导入功能示例，不与任何指定视频音频对应。不要用它判断视频字幕对齐效果。

## 隐私与权限

- 唯一显式扩展权限为 `storage`，仅保存播放速度和循环设置。
- 内容脚本仅在 `https://www.youtube.com/*` 运行。
- 不请求所有网站权限、浏览历史或下载管理权限。
- 字幕请求直接发送给当前 YouTube 页面使用的 YouTube 字幕接口。
- 无服务器、无遥测、无远程 JavaScript、无语音识别或 AI 调用。
- 录音仅存在当前页面内存。切换句子、切换视频、刷新或收起面板会清除录音；请先下载要保留的录音。
- 麦克风由 Chrome 网站权限管理，随时可在地址栏的网站设置撤销。

## 边界

- 第一版支持桌面普通 `/watch?v=...` 视频；不支持 Shorts、嵌入播放器，不保证直播正常。
- YouTube 会调整字幕接口与页面结构，也可能要求额外的字幕请求令牌，因此自动提取不保证对每个视频可用；提供字幕导入和屏幕字幕收集作为替代。
- 屏幕字幕收集会合并逐词扩展、去除滚动前文，并按句末标点或字幕停顿分段；无标点时约每 28 词或 12 秒切成适合跟读的片段。当前片段随播放持续更新。
- 收集仅覆盖已经播放的部分，时间是采样估计值；从半句话开始收集、跳转播放或后台节流可能影响完整性与精度。
- 自动下载和导入字幕使用原始分段；屏幕字幕按上述规则合并，不承诺每条都是完整语法句子。
- 播放在约 100ms 轮询内停止，后台标签页不适合精确跟读。
- 不提供音素级发音评分、实时纠音或翻译；当前版本以录音对照练习为主。
- 只保留当前句的一段录音，不保存练习历史。

## 开发与验证

纯 JavaScript + CSS 的 Manifest V3 扩展，无构建步骤，无运行依赖。Node.js 18+ 可执行：

```bash
npm test
```

```bash
npm run check
```

核心文件：`manifest.json` 声明入口，`bridge.js` 在页面主环境读取字幕，`core.js` 解析字幕，`content.js` 在隔离环境内处理界面、播放器与录音，`panel.css` 提供 Shadow DOM 样式，`background.js` 处理工具栏按钮，`help.html` 提供中文使用说明。

浏览器验证细节见 `TESTING.md`。
